# Impulsion Bootstrap extensions

This reference lists every Impulsion customization on top of Bootstrap 5.3.8.
The source of truth is [the settings partial](scss/impulsion/_settings.scss) and
[the maps partial](scss/impulsion/_maps.scss).

Unless overridden by a consuming project, `$spacer` is `1rem`. All pixel
equivalents for rem values below assume a `16px` root font size. Fixed pixel
spacing values do not change with the root font size.

## Theme and options

| Sass setting | Impulsion default | Bootstrap default |
| --- | --- | --- |
| `$primary` | `#6fc2b1` | `$blue` (`#0d6efd`) |
| `$secondary` | `#f4ac63` | `$gray-600` (`#6c757d`) |
| `$enable-negative-margins` | `true` | `false` |

The colors feed Bootstrap's derived theme colors, CSS variables, utilities, and
components. They are not limited to `.text-primary` and `.bg-secondary`.
These settings use `!default`, so a project can override them before importing
an Impulsion Bootstrap entry point.

## Breakpoint and containers

| Sass map | Added key | Value |
| --- | --- | --- |
| `$grid-breakpoints` | `xxxl` | `1600px` |
| `$container-max-widths` | `xxxl` | `1520px` |

The `xxxl` breakpoint was part of the original fork. The `1520px` container
maximum was added during the 5.3.8 upgrade. These are project conventions, not
Bootstrap defaults. All six upstream breakpoint values remain unchanged.

At viewport widths of `1600px` and above:

- Responsive classes with the `xxxl` infix become active and remain active at
  larger widths, unless overridden by other CSS.
- `.container`, `.container-sm`, `.container-md`, `.container-lg`,
  `.container-xl`, `.container-xxl`, and `.container-xxxl` have a maximum width
  of `1520px`.
- A centered container in a full-width `1600px` viewport leaves `40px` outside
  each side, in addition to its internal padding.

Below `1600px`, `.container-xxxl` is fluid. Existing containers keep their
upstream behavior at smaller breakpoints, including a `1320px` maximum for
`.container` from `1400px` up to (but below) `1600px`. `.container-fluid` remains
fluid at every width.

| Example | Effect at `1600px` and above |
| --- | --- |
| `col-xxxl-6` | Half-width grid column |
| `mt-xxxl-60px` | `margin-top: 60px !important` |
| `mt-xxxl-n60px` | `margin-top: -60px !important` |
| `d-xxxl-none` | `display: none !important` |

The breakpoint also extends Bootstrap's other responsive utilities and layout
rules. It does not make nonresponsive utilities responsive; for example,
`fs-xxxl-sm` is not generated by this extension.

## Extended spacing scale

These additions to `$spacers` preserve Bootstrap's existing keys `0` through `5`.

| Suffix | Sass value | Default CSS value | Pixel equivalent |
| --- | --- | --- | --- |
| `6` | `$spacer * 4` | `4rem` | 64px |
| `7` | `$spacer * 5` | `5rem` | 80px |
| `8` | `$spacer * 6` | `6rem` | 96px |
| `9` | `$spacer * 7` | `7rem` | 112px |
| `10` | `$spacer * 8` | `8rem` | 128px |
| `11` | `$spacer * 9` | `9rem` | 144px |
| `12` | `$spacer * 10` | `10rem` | 160px |
| `13` | `$spacer * 11` | `11rem` | 176px |
| `14` | `$spacer * 12` | `12rem` | 192px |
| `15` | `$spacer * 13` | `13rem` | 208px |

The fixed pixel additions are:

| Suffix | CSS value |
| --- | --- |
| `10px` | `10px` |
| `20px` | `20px` |
| `30px` | `30px` |
| `40px` | `40px` |
| `50px` | `50px` |
| `60px` | `60px` |
| `70px` | `70px` |
| `80px` | `80px` |
| `90px` | `90px` |
| `100px` | `100px` |
| `125px` | `125px` |
| `150px` | `150px` |

These sizes are available for:

- Margins: `m`, `mt`, `mb`, `ms`, `me`, `mx`, and `my`.
- Padding: `p`, `pt`, `pb`, `ps`, `pe`, `px`, and `py`.
- Gaps: `gap`, `row-gap`, and `column-gap`.
- Grid gutters: `g`, `gx`, and `gy`.

Each family supports the existing responsive infixes `sm`, `md`, `lg`, `xl`,
and `xxl`, plus `xxxl`. Omit the infix to apply a utility at all widths.
The `s` and `e` suffixes mean start and end: left/right in the LTR build and
right/left in the RTL build.

Negative margins are enabled for both upstream and extended spacing sizes.
Insert `n` before the size; negative padding, gaps, and gutters are not generated.

| Example | Default effect |
| --- | --- |
| `mt-6` | `margin-top: 4rem !important` (64px) |
| `mt-n6` | `margin-top: -4rem !important` (-64px) |
| `mt-60px` | `margin-top: 60px !important` |
| `mt-n60px` | `margin-top: -60px !important` |
| `p-md-10` | `padding: 8rem !important` from 768px |
| `gap-20px` | `gap: 20px !important` |
| `gx-xxxl-40px` | Horizontal grid gutter of 40px from 1600px |

Spacing utilities retain Bootstrap's default `!important` behavior. Grid gutter
classes set `--bs-gutter-x` and/or `--bs-gutter-y` for Bootstrap's grid instead.

## Typography

| Class | Custom font size | Pixel equivalent | Change |
| --- | --- | --- | --- |
| `fs-7` | `.875rem` | 14px | Added |
| `fs-8` | `.75rem` | 12px | Added |
| `fs-sm` | `.9375rem` | 15px | Added |
| `fs-md` | `1.125rem` | 18px | Added |
| `display-6` | `2.75rem` target | 44px target | Increased from `2.5rem` |

The `fs-sm` and `fs-md` names represent font sizes, not responsive breakpoints.
These four added font sizes apply at all viewport widths and use `!important`.

`display-6` retains Bootstrap's responsive font sizing (RFS). With the default
configuration, its generated size is `calc(1.4rem + 1.8vw)` below `1200px`, then
`2.75rem` at `1200px` and above. The existing `fs-1` class remains unchanged:
its RFS target is `2.5rem` (40px at a 16px root font size).

## Sass integration

The four entry points already load both Impulsion partials:

| Entry point | Relevant output |
| --- | --- |
| `scss/bootstrap.scss` | Full components, grid, helpers, and utilities |
| `scss/bootstrap-grid.scss` | Grid, containers, and selected layout/spacing utilities; excludes gap and font-size utilities |
| `scss/bootstrap-utilities.scss` | Theme variables, helpers, and utilities; excludes grid/container and display-heading classes |
| `scss/bootstrap-reboot.scss` | Theme variables and Reboot; excludes spacing and typography utility classes |

Consumers that assemble their own import stack must include the Impulsion
partials explicitly. Paths in this example are relative to the repository root;
adapt them to the consuming project's location:

```scss
@import "scss/functions";
@import "scss/impulsion/settings";
@import "scss/variables";
@import "scss/variables-dark";
@import "scss/impulsion/maps";
@import "scss/maps";
@import "scss/mixins";
@import "scss/utilities";
// Import the needed components and helpers here.
@import "scss/utilities/api";
```

Settings must load before variables so derived theme values use the chosen
colors. Custom maps must load before Bootstrap's derived maps so negative
spacers, gutters, and generated utilities include the extensions. The Impulsion
map merges replace matching keys with the values documented above; further
project-specific map changes belong after the Impulsion maps and before
Bootstrap's maps.

Keep Bootstrap's core `_variables.scss` unchanged when upgrading. Preserve the
two custom partials and their imports in all four entry points.

## Build and validation

Generated bundles in `dist/` and `js/dist/` are ignored by Git. A fresh checkout
must build them before use or packaging. See the [README](README.md#build-and-verify)
for installation and build commands.

After building, run `npm run test-impulsion`. The checks cover all 16 CSS bundle
variants (full, grid, utilities, and Reboot; expanded/minified; LTR/RTL), including
custom spacing at every breakpoint, colors, containers, font sizes, and RTL
start/end spacing. Upstream Sass and JavaScript tests are separate checks.
